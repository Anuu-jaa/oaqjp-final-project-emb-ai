# Emotion Detector

## Final Project

An AI-based web application that detects emotions from text using Watson NLP and Flask.

### Technologies Used

- Python
- Watson NLP
- Flask
- HTML/CSS/JavaScript
- Pylint
- Unit Testing

### Project Structure

- `EmotionDetection/emotion_detection.py` - Emotion detection application
- `EmotionDetection/__init__.py` - Python package initialization
- `server.py` - Flask web application
- `test_emotion_detection.py` - Unit tests
- `templates/index.html` - Web interface
- `static/mywebscript.js` - Frontend JavaScript
